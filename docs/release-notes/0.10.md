# Release 0.10 — Settings and configuration

Closed on 2026-10-25.

## What this release is

The map is clean again: everything that was a button on it now lives behind a gear. Adults get three clear settings screens instead of one long "Gerir" page. The game explains itself, the installed app has its own name and icon, and a new child can enter already as themselves.

## What now exists

- **The menu.** The map's top bar has only the greeting and a gear. The gear opens a panel with "Como jogar", "Como instalar", the adults' settings and "Trocar de perfil" last. It closes with ✕, a tap outside, or the back gesture.
- **Three settings screens, for adults.**
  - **Pessoas:** the profiles, with a new "Mudar nome" for anyone, archive and reactivate, a new-profile form, and the invite.
  - **Tarefas:** every task of a person, and the repeating ones, in one place, with "Nova tarefa".
  - **Regras do jogo:** how many tokens a task gives and what each prize costs, the size of the crew and of the tavern, a new "Dias à espera", and the restart button last. The restart now says "mundo", never the theme's word.
- **"Como jogar".** A popup over the map that explains the game with pictures from the game itself and the real numbers of your world. It opens by itself once for each person on each phone, and is always in the menu.
- **"Como instalar".** It shows what fits the phone: already installed, the install button, the steps for iPhone, or the steps for Android's menu.
- **"Atualizar".** The menu shows the version and its date. When a newer version is out, an "Atualizar" button appears and loads it. Offline, nothing shows and nothing breaks.
- **The pirate app's name and icon.** On the home screen it is "Ilha dos Piratas", with the parrot's face. The title of the page matches.
- **iPhone: add from where you are.** Adding the app to the home screen from a world you are already in opens the app already there, on your profile, with nothing to do again.
- **An invite for each child.** In Pessoas, each child has their own invite: a link and a QR code that opens the app already on that child, on a new phone. A phone that entered this way stays on that child, with no "Trocar de perfil". Clearing the app's data frees it, and it frees itself if the child is archived.

## Good to know

- The rules in Firebase did not change in this release: nothing to publish.
- On an iPhone, the name and icon of an app already on the home screen never change. To see the new ones, remove the app and add it again.
- The page on an iPhone no longer has a web app manifest. That is what lets the app start where it was added from.
- A phone on an older version opens a child's link and shows the profile picker, and refuses it when pasted. "Atualizar" fixes that.
