# Release 0.5 — Children pilot

Closed on 2026-10-20.

## What this release is

A real week of use by the children, with no rewards yet, to check that they use the app for its own sake before any reward exists.

## Result

The children used the app without being called, completed tasks quickly, did not find it to be more work, and did not create tasks just to have something to complete. All four exit criteria were met, so rewards go ahead.

Release 0.6 — Rewards: each completed task brings a reward, opened on Sunday, and what comes out of it joins the person's collection.
