# Release 0.3 — Recurrence and alerts

Closed on 2026-10-20.

## What this release is

The tasks that come back by themselves. Instead of creating the same task every day, an adult defines it once, and the app brings it back each day, week or month.

## What now exists

- **Recurring tasks.** In management, an adult defines a task once: its title, whether it is daily, weekly or monthly, its difficulty, who it is for, an optional question, and whether it is a "big" one. It can be turned off and on again, and it is never deleted.
- **They appear on their own.** When the app opens, or when someone switches profile, the day's, week's or month's tasks are there. Opening the app twice never creates a task twice.
- **No pile-up.** A task that was not done stays on the board until it is done, with no penalty, and no second copy is added while it is open. Doing a late task today counts for today.
- **Planning big tasks.** A big task can get a day and a moment ("after dinner", or your own words). The plan can be changed at any time, and nothing records that it changed.
- **A gentle visual alert.** The board on the map glows when a planned task is due: strongly on the day, softly the day before. There are no notifications and no scolding.

## Good to know

- Changing a recurring task's title only affects the tasks created after the change.
- The first time a phone opens the app on a given day, it waits a few seconds for the server before adding the day's tasks, so it does not add duplicates.
