# Release 0.2 — Core

Closed on 2026-10-19.

## What this release is

The first version the family can really use. The app now does its main job: a family has a world, each person has a profile, and tasks are completed on the phone.

## What now exists

- **Join the family's world** with a link or a QR code. Each device then picks who it is, Netflix-style. An adult profile can manage the family; a child profile only sees and completes its own tasks.
- **The map** shows what is still to do. **The board** is where tasks are created: adults create for anyone, and a child can add up to 3 tasks of their own per day, only naming them.
- **The check-in** completes a task in two taps from the map. When a task has a question, the answer is part of it. Answering "no" leaves the task open, the character answers kindly and nothing is recorded. A button lets a child say "I think I did better".
- **Two phones stay in sync**, and the app works without a network: what is done offline appears again when the phone reconnects, with no duplicates.
- **The app installs on the home screen** and opens offline. It has the name and icon of the world's theme, and it offers to install itself, with the steps for iPhone.
- **Themes.** The world's theme is chosen when the world is created and every device follows it. A second theme, "Tema quinta", shows that a theme changes names, colours and icons without touching anything else.

## Good to know

- On iPhone, a join link opened in Safari does not join: install the app first, then paste the link inside it.
- Always use the same address, so the data stays in one place.
- Nothing is earned yet: rewards and the collection come in later releases.
