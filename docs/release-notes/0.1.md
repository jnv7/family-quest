# Release 0.1 — Foundations

Closed on 2026-10-18.

## What this release is

The groundwork. There is nothing to play with yet: the app opens on a start page that says it is under construction, and shows its version.

## What now exists

- The app is published on GitHub Pages and opens on a phone over HTTPS.
- The rules that protect the family's data are written and tested. Only members of a family can read it, each person completes only their own tasks, a completed task never reopens, and nothing earned can be deleted.
- The data layer works offline-first, with two interchangeable implementations: the real one on Firebase, and an in-memory one for tests. One shared test suite keeps them identical.
- Dates and weeks follow Lisbon time, including the clock change on 25 October 2026 and the 53rd week of 2026.
- The interface text is in European Portuguese and comes from text files. A first, minimal theme (emoji and plain names) proves that a theme can change every name without touching the code.
- Automatic checks run on every change: types, unit tests, the data rules, the Firebase adapter, theme validation, and a guard that keeps theme words out of the code.

## What changed from the plan

- The app is served from the product owner's own domain, because the GitHub account has a custom domain. Install it on the phone always from that same address, so that the data stays in one place.
