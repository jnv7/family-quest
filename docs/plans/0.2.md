## [x] B. Exit verification (product owner, on real phones)

Use the live address, `https://www.jnvasconcelos.com/family-quest/`. GitHub Pages redirects `jnv7.github.io/family-quest/` there. Tick each line and write down anything odd in an issue or in a note to the tech lead.

**Setup:** one iPhone (adult) and one Android phone (child).

1. **Create and join:**
   - on the iPhone, create a world and create a child profile;
   - send the join link to the Android phone, install the app from it, open it and pick the child profile.
2. **Two devices stay in sync:**
   - the adult creates a task for the child, and it appears on the Android phone within a few seconds;
   - the child completes it, and the adult sees it as done in management.
3. **Airplane mode creates no duplicates:**
   - put the Android phone in airplane mode, complete one task and create one ad hoc task;
   - close the app, reopen it (still offline), and both changes are still shown;
   - turn the network back on: after sync, each task exists exactly once on both phones.
4. **The installed app opens offline:** with the network off, launch the installed app on both phones. It opens on the map with the last data.
5. **A second theme works without code:**
   - create a second world with the farm theme on another device or browser;
   - names, colours and icons change;
   - nothing in the code or the data was touched.
6. **A whole day of use:** use the app for one full day as an adult, without touching the code. Note every moment of friction (more than 2 taps to complete, unclear text).
7. **Read quota (`SPEC.md` §13):**
   - at the end of that day, open Firebase console → Firestore → Usage, and write down reads, writes and listeners for the day;
   - the free limit is 50,000 reads/day; anything above 10% of that for one family needs a look before 0.3.
